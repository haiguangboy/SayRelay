# 产品化记录

## 当前版本：Ubuntu 本地语音输入原型

- Ubuntu 24.04 / GNOME / Wayland。
- 本地 Whisper 识别、简体转换和中文标点。
- Codex 桌面、浏览器、编辑器和终端的当前焦点粘贴。
- systemd 用户服务、GNOME 快捷键、GTK 设置窗口。
- 自动粘贴授权记忆、服务重启恢复和失败保留提示。
- 本机 / 小米遥控器输入切换、ATVV 蓝牙握手、电量与连接状态。
- RC003 语音键的 evdev 接入、重复过滤、独占与一次性设备授权。
- RC003 真机录音、转写及 Wayland 测试输入框实际粘贴通过，用户确认可向 Codex 输入。
- 遥控器确定键向当前应用发送一次 Enter，长按不连发。
- Home 打开原生窗口概览，左右选择、确定进入；平时左右使用系统应用切换快捷键。用户已在本机 RC003 上确认实际按键流程可用。

## 下一阶段

1. 扩展遥控器实际语音输入试用；验证休眠唤醒、断连恢复与长时间使用。
2. 评估其他固件与非 Pro 型号，按证据扩展兼容列表。
3. 扩展多工作区、多窗口的导航体验测试，为其余遥控器按键增加动作设置。
4. 为 Ubuntu 打包 AppImage/deb 或独立模型下载器，避免用户手动准备 1 GB 以上模型。
5. 针对中英混说、专有名词和更强本地模型做可重复评测，再决定默认模型。

## 公开发布原则

- Git 仓库只放源码、测试、文档和小型元数据，不放用户录音、授权令牌和大模型权重。
- 发布页提供模型下载、SHA-256 和上游许可说明。
- 先发布可审阅的源码版本，再发布安装包；每个版本记录 Ubuntu、GNOME、模型和依赖版本。
